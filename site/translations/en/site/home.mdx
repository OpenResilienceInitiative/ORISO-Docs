## Docs and Understand work together

| Source | What it contains | How it is produced |
|---|---|---|
| **Docs — this site** | Technical instructions, product reference, architecture, operations and decisions | Written by people and versioned in `ORISO-Docs` |
| [Understand](https://understand.oriso.org/) | The high-level overview and code structure: files, functions and call paths per repository | Code graphs generated deterministically from source; overview content is maintained separately |
| [Canonical legal documentation](https://understand.oriso.org/legal/dsfa/) | The DPIA with evidence from the code | Maintained on Understand; Docs links to it rather than duplicating the full legal text |

Start on Understand for an overview, then follow its links to Docs for technical detail.
Use the links above to return from Docs to Understand or to the canonical legal documentation.

When the documentation and a graph disagree, compare their source branches and check the linked
code. A graph built from `main` does not prove what is implemented or deployed on `dev`.
