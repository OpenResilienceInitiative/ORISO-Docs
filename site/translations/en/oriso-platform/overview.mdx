# Operator setup

[ORISO-Helm](https://github.com/OpenResilienceInitiative/ORISO-Helm) defines the supported Kubernetes deployment. Use the chart and image revisions approved for the target environment. The [Kubernetes deployment guide](/docs/platform/kubernetes-deployment) explains the source repositories, chart values, and ingress routing.

1. For a disposable developer installation, start with [Install and run locally](/docs/platform/install-and-run-locally). Its managed runner provisions the local services and sample data.
2. For an operator installation or upgrade, establish the intended release and existing database state. Follow [Deploy backend services](/oriso-platform/deploy-backend-services), [Set up databases](/oriso-platform/setup-databases), and [Configure Keycloak](/oriso-platform/configure-keycloak).
3. For recovery, start with [Backup and recovery](/oriso-platform/backup-configuration). Restore into a compatible isolated instance and verify it before deciding on a cutover.
4. Record the deployed revisions and the results of the [post-deployment checks](/oriso-platform/post-deployment).

Earlier server and deployment instructions are retained in the navigation archive for historical reference.
