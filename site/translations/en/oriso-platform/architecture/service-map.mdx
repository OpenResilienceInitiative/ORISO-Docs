New to ORISO? Start here. The map shows four layers (people, apps, platform services, infrastructure).
Click any box for what it does and how you use it, or pick a journey — "Seeker gets help",
"Seeker → agency → counsellor (in code)", supervision, case handover, encrypted chat & calls — to see
the path a request takes, with file and line references.

[Open the service map full screen](/service-map/)

<iframe src="/service-map/" title="ORISO Service Map" style={{width: '100%', height: '1400px', border: 0}} />

Sources: READMEs, the API specs in each service's `api/` folder, Frontend components and the Admin
routes in `appConfig.ts`. Infrastructure boxes describe each component's usual role; per-service
wiring there was not traced in code. A CI check (`tools/service-map`) fails as soon as ORISO-Helm deploys a service the map does not show.
