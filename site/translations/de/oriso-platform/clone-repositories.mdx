# ORISO-Repositories klonen

Klonen Sie das aktuelle Chart in Ihr Arbeitsverzeichnis. Das Chart `online-counseling` liegt im Stammverzeichnis von ORISO-Helm.

```bash
mkdir -p ~/online-beratung
cd ~/online-beratung
git clone https://github.com/OpenResilienceInitiative/ORISO-Helm.git
cd ORISO-Helm
ls Chart.yaml charts templates
```

Klonen Sie für Änderungen an einem Service das zuständige Repository. Dort liegen auch die Changelogs für UserService, AgencyService, TenantService und ConsultingTypeService. Die Anwendung und den Administrationsbereich finden Sie in ORISO-Frontend und ORISO-Admin. [Repository-Übersicht](/docs/platform/repository-map)
