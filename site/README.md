# ORISO documentation site (Fumadocs)

Developer and product documentation, built with [Fumadocs](https://fumadocs.dev) on Next.js
(static export) and served by nginx at **https://docs.oriso.org/**.

## What it renders

| Route | Source of truth | How it gets here |
|---|---|---|
| `/produkt/**`, `/plattform/**`, `/betrieb/**` | the repository's MDX/Markdown pages, navigated by `../docs.json` | `scripts/sync-content.mjs` migrates the Mintlify components to their Fumadocs equivalents |
| `/decisions/*` | `../oriso-platform/decisions/ADR-*.md` | same script |

Everything under `content/docs` except `index.mdx` is generated and git-ignored. Edit the sources
in the repository root, not the generated copies.

**The DPIA is deliberately not here.** It is a standalone living document at
`https://understand.oriso.org/legal/dsfa/`, generated by `../tools/build-dsfa-page.py`, with its
own evidence dialogs, KDG/GDPR preset and print layout.

## Migration rules (scripts/sync-content.mjs)

- `docs.json` is the navigation source: one root folder per tab, one subfolder per group.
- `<Note>/<Info>/<Tip>/<Check>/<Warning>` become `<Callout>` with the matching type,
  `<CardGroup>` becomes `<Cards>`, `<AccordionGroup>` becomes `<Accordions>`, `<Frame>` is dropped.
- `<Tabs><Tab title="…">` becomes Fumadocs' `<Tabs items={[…]}><Tab value="…">`. This runs on the
  whole file before the code-fence split, because tab bodies contain fenced blocks.
- Curly braces in prose are escaped — MDX would read `token={JWT}` as a JSX expression.
- Replacements never touch fenced code: the runbooks contain heredocs with `<<EOF`.
- `.md` sources stay `.md` so that angle brackets in examples are not parsed as JSX.

## Commands

```bash
pnpm install
pnpm dev          # sync, then next dev  -> http://localhost:3000/dokumentation/
pnpm build        # sync, then a static export for the /dokumentation path prefix
pnpm build:root   # the same for a domain root — this is what docs.oriso.org serves
```

## Deploying

```bash
pnpm build:root && rsync -az --delete out/ root@49.13.11.37:/var/www/docs-site/
```

Vhost `/etc/nginx/sites-available/docs.oriso.org`, certificate via certbot.
`understand.oriso.org/dokumentation/*` redirects here.
