## Three complementary sources

| Source | What it contains | How it is produced |
|---|---|---|
| **This site** | Product, architecture, operations and decisions | Written by people and versioned in `ORISO-Docs` |
| [Code graph](https://understand.oriso.org/) | Source structure: files, functions and call paths per repository | Generated nightly, deterministically and without a language model |
| [Legal documentation](https://understand.oriso.org/legal/dsfa/) | The DPIA with evidence from the code | Built from maintained chapters, with evidence checked against the graph |

When this site and the graph disagree about code structure, use the graph as the lead: it is
generated from source while these explanations are maintained by people.
