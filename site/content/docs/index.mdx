## Die drei Wahrheiten nebeneinander

| Wo | Was dort steht | Wie es entsteht |
|---|---|---|
| **Diese Seite** | Erklärung: Produkt, Architektur, Betrieb, Entscheidungen | von Hand geschrieben, im Repository `ORISO-Docs` versioniert |
| [Code-Graph](https://understand.oriso.org/) | der Quellcode selbst: Dateien, Funktionen, Aufrufwege je Repository | nächtlich erzeugt, deterministisch und ohne Sprachmodell |
| [Rechtliches](https://understand.oriso.org/legal/dsfa/) | Datenschutz-Folgenabschätzung mit Belegen aus dem Code | aus Kapiteltexten erzeugt, Belege gegen den Graphen geprüft |

Widersprechen sich Seite und Graph, gilt der Graph — er wird aus dem Code gebaut, dieser Text von
Menschen gepflegt.
