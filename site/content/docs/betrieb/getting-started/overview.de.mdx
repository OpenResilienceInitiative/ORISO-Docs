## Serveranforderungen

### Hardwareanforderungen

#### Mindestanforderungen (Tests/Entwicklung)

- **CPU**: 4 Kerne (Intel/AMD x64)
- **RAM**: 8GB
- **Datenträger**: 50GB SSD
- **Netzwerk**: 1 Gbps

#### Empfohlen (Produktion)

- **CPU**: 8+ Kerne (Intel/AMD x64)
- **RAM**: 16GB+
- **Datenträger**: 100GB+ SSD (vorzugsweise NVMe)
- **Netzwerk**: 1 Gbps+
- **Backup-Speicher**: Externe Sicherungslösung

<Callout>
Für produktive Bereitstellungen empfehlen wir ausdrücklich die empfohlenen Spezifikationen, um optimale Leistung und Zuverlässigkeit sicherzustellen.
</Callout>

### Softwareanforderungen

#### Betriebssystem

- **Bevorzugt**: Ubuntu Server 22.04 LTS (empfohlen)
- **Alternative**: Ubuntu Server 20.04 LTS
- **Architektur**: x86_64 (amd64)
- **Neuinstallation**: Frische Installation (keine bestehenden Dienste)

#### Zugriffsvoraussetzungen

- **SSH-Zugriff**: Root- oder sudo-Benutzer
- **Internetzugang**: Für die Paketinstallation erforderlich
- **Öffentliche IP**: Für externen Zugriff erforderlich
- **Domainname**: Optional (für SSL/DNS)

### Netzwerkanforderungen

#### Erforderliche Ports (externer Zugriff)

| Port | Dienst | Beschreibung |
|------|---------|-------------|
| `22` | SSH | Zugriff über Secure Shell |
| `80` | HTTP | Ingress Controller (Weiterleitung auf HTTPS) |
| `443` | HTTPS | Ingress Controller (TLS-Terminierung) |
| `6443` | Kubernetes API | Optional für kubectl-Zugriff |

#### Dienstports (intern – ClusterIP)

Alle Dienste sind intern über Kubernetes-DNS erreichbar. Externer Zugriff erfolgt über Ingress (Ports 80/443).

| Dienst | Port | Muster der internen URL |
|---------|------|---------------------|
| MariaDB | 3306 | `oriso-platform-mariadb.caritas.svc.cluster.local:3306` |
| MongoDB | 27017 | `oriso-platform-mongodb.caritas.svc.cluster.local:27017` |
| PostgreSQL | 5432 | `oriso-platform-postgresql.caritas.svc.cluster.local:5432` |
| Redis | 6379 | `oriso-platform-redis.caritas.svc.cluster.local:6379` |
| RabbitMQ | 5672 | `oriso-platform-rabbitmq.caritas.svc.cluster.local:5672` |
| Keycloak | 8080 | `oriso-platform-keycloak.caritas.svc.cluster.local:8080` |
| TenantService | 8081 | `oriso-platform-tenantservice.caritas.svc.cluster.local:8081` |
| UserService | 8082 | `oriso-platform-userservice.caritas.svc.cluster.local:8082` |
| ConsultingTypeService | 8083 | `oriso-platform-consultingtypeservice.caritas.svc.cluster.local:8083` |
| AgencyService | 8084 | `oriso-platform-agencyservice.caritas.svc.cluster.local:8084` |
| Matrix Synapse | 8008 | `oriso-platform-matrix-synapse.caritas.svc.cluster.local:8008` |
| Health Dashboard | 9001 | `oriso-platform-health-dashboard.caritas.svc.cluster.local:9001` |
| SignOZ | 3001 | `signoz-frontend.platform.svc.cluster.local:3301` |

<Callout type="warn">
Stellen Sie sicher, dass alle erforderlichen Ports in der Firewall-Konfiguration geöffnet sind. Einzelheiten finden Sie unter [Netzwerk- und Firewall-Konfiguration](/de/betrieb/getting-started/network-firewall).
</Callout>

## Schnellstart

Wenn Sie beginnen möchten, führen Sie zuerst diese wichtigen Schritte aus:

1. **Voraussetzungen prüfen** – Stellen Sie sicher, dass Ihr Server die Mindestanforderungen an Hardware und Software erfüllt.
2. **Mit dem Server verbinden** – Melden Sie sich per SSH mit Root- oder sudo-Zugriff an Ihrem Ubuntu-Server an.
3. **Einrichtungsanleitung befolgen** – Fahren Sie mit der [Ersten Servereinrichtung](/de/betrieb/getting-started/initial-setup) fort.

<Callout type="success">
Nach Abschluss aller Einrichtungsschritte verfügen Sie über eine vollständig funktionsfähige ORISO-Plattform mit:
- Allen Diensten auf Kubernetes
- Konfigurierten und befüllten Datenbanken
- Funktionierender Authentifizierung (Keycloak)
- Erreichbarem Frontend und Admin
- Betriebsbereitem Matrix-Chat
- Konfigurierter Überwachung
</Callout>
