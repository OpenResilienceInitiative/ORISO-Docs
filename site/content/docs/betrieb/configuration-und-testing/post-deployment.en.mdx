---
title: "Post-deployment checks"
description: "Verify the deployed versions, database migrations, authentication and application behavior."
source: "oriso-platform/post-deployment.mdx"
---

Check the target environment and release before gathering evidence. Verify each result against the revision that is actually running.

1. Compare the [deployed image versions](/en/plattform/core-systems/kubernetes-deployment) with the intended images. Check rollout readiness and unexpected replicas still using an older image.
2. Verify the [database migration checks](/en/betrieb/deployment/setup-databases) on the affected services. Confirm the expected changesets and ready application state.
3. Verify the [public HTTPS issuer](/en/betrieb/deployment/configure-keycloak), then sign in and sign out with an approved synthetic account.
4. Run the affected application workflow with synthetic data. Record the environment, source or image revision, check and result.
5. If the release changes recovery behavior, verify the artifact and the isolated restore according to [Backup and recovery](/en/betrieb/operations/backup-configuration).
