Support-Adresse

Die Plattform kann eine gemeinsame E-Mail-Adresse hinterlegen. Beratende sehen sie als Kontakt, wenn für ihre Beratungsstelle keine Admin-Person für einen Chat verfügbar ist. Ein Klick öffnet das eigene E-Mail-Programm.

Wer sieht und ändert die Einstellung?

Plattform-Admins können die Adresse in den globalen Einstellungen bearbeiten oder löschen. Andere Rollen sehen die Kachel dort, wo sie Zugriff auf diese Einstellungen haben, ohne sie zu bearbeiten. Beratende sehen die Adresse nur im beschriebenen Fall; Ratsuchenden wird hier keine Adresse angezeigt.

Was passiert beim Ändern?

Die Adresse wird ohne Leerzeichen am Rand gespeichert. Ein leeres Feld entfernt sie. Ist keine gültige Adresse hinterlegt, erscheint der Hinweis ohne E-Mail-Link. Können die Admin-Kontakte nicht geladen werden, erscheint ein eigener Fehlerhinweis; daraus wird nicht geschlossen, dass keine Admin-Person existiert.

Die Adresse ist Teil der öffentlich ausgelieferten Anwendungseinstellungen. Verwenden Sie deshalb ein gemeinsames Postfach und keine vertrauliche persönliche Adresse.

Wer sieht die Einstellung?

Die Kachel liegt in den globalen Einstellungen. Diese Ansicht ist für Plattform-Admins mit Änderungsrecht für Träger erreichbar; Wer ausschließlich Träger- oder Beratungsstellen-Admin ist, sieht diese globale Ansicht nicht.

Stand und Quellen

Das beschriebene Verhalten ist im Quellcode vorhanden. Eine Prüfung der aktuell bereitgestellten Umgebung ist damit nicht verbunden. Stand: 5. November 2026.

Support address

The platform can set a shared email address. Counsellors see it as a contact when their counselling centre has no administrator available for chat. Selecting it opens their own email application.

Who can see and change it?

Platform admins can edit or clear the address in global settings. Other roles see the tile without editing it where they have access to those settings. Counsellors see the address only in the situation above; this view does not show it to advice seekers.

What happens when it changes?

Leading and trailing spaces are removed before saving. An empty field clears the address. If no valid address is configured, the notice appears without an email link. If the admin contacts cannot be loaded, a separate error is shown; the app does not assume that no administrator exists.

The address is part of the publicly served application settings. Use a shared mailbox rather than a confidential personal address.

Who sees the setting?

The card is in global settings. This view is available to platform admins with permission to update providers; people with only provider- or counselling-centre-admin roles do not see this global view.

Status and sources

The behaviour described is present in source code. This does not verify the currently deployed environment. As of 5 November 2026.
