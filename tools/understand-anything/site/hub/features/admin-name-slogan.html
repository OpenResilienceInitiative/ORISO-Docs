Benennung und Slogan

In dieser Kachel pflegen Sie den Namen und den Slogan einer Organisation. Beide Felder sind erforderlich.

Wer kann die Angaben ändern?

Plattform-Admins können die Angaben bearbeiten. Für Träger-Admins hängt die Bearbeitung von den freigegebenen Rechten für Stammdaten und Erscheinungsbild ab; solange diese Rechte nicht bestätigt sind, bleibt die Kachel schreibgeschützt. In der Bearbeitung einer Beratungsstelle gibt es diese Kachel nicht.

Was passiert beim Speichern?

Der Admin speichert die Werte für die ausgewählte Organisation. Die Anwendung verwendet den Namen unter anderem als Seitentitel und den Slogan als Seitenbeschreibung für die Browser-Metadaten.

Stand und Quellen

Die beschriebenen Felder und ihre Verwendung sind im Quellcode vorhanden. Eine Prüfung der aktuell bereitgestellten Umgebung ist damit nicht verbunden. Stand: 5. November 2026.

Name and slogan

Use this tile to maintain an organisation’s name and slogan. Both fields are required.

Who can change them?

Platform admins can edit the values. For provider admins, editing depends on the granted rights for master data and appearance; the tile stays read-only until those rights are confirmed. The counselling-centre edit view does not have this tile.

What happens when you save?

The Admin saves the values for the selected organisation. The application uses the name, among other things, as the page title and the slogan as the page description in browser metadata.

Status and sources

The fields and uses described are present in source code. This does not verify the currently deployed environment. As of 5 November 2026.
