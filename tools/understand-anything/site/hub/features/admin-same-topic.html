Zwei Beratungen zum gleichen Thema

Diese plattformweite Einstellung betrifft Ratsuchende mit mehreren angenommenen Einzelberatungen zum selben Hauptthema. Eine weitere Beratung wird dadurch nicht verhindert.

Wer kann die Einstellung ändern?

Plattform-Admins können die Kachel bearbeiten. Für Träger-Admins, die diese Seite öffnen können, ist sie nicht bearbeitbar.

Was passiert?

Wird eine neue Anfrage angenommen und gibt es bereits eine andere angenommene Einzelberatung zum gleichen Thema, versucht das System, dort einmal einen Hinweis im Gespräch und in der Glocke zu hinterlegen. Eine E-Mail hängt von den Benachrichtigungseinstellungen ab. Der Hinweis nennt die andere Beratungsstelle nicht. Gruppenberatungen zählen nicht.

Derzeit ist nur diese Benachrichtigung auswählbar. Die weiteren angezeigten Möglichkeiten sind noch nicht verfügbar. Falls die Zustellung fehlschlägt, wird die Annahme der neuen Beratung nicht rückgängig gemacht.

Two conversations on the same topic

This platform-wide setting concerns advice seekers with multiple accepted one-to-one conversations about the same main topic. It does not prevent another conversation.

Who can change the setting?

Platform admins can edit the tile. Provider admins who can open this page cannot edit it.

What happens?

When a new enquiry is accepted and another accepted one-to-one conversation has the same main topic, the system attempts to add a one-time notice to that conversation and its notification bell. Email depends on notification preferences. The notice does not name the other counselling centre. Group conversations do not count.

Only this notification is currently selectable. The other displayed options are not yet available. If delivery fails, acceptance of the new conversation is not rolled back.
