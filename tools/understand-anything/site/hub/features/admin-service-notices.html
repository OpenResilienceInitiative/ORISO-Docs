Systemhinweise

Plattform-Admins können mit Systemhinweisen geplante Wartung an Admins von Beratungsstellen ankündigen.

Wer kann sie verwenden?

Die Ansicht ist für Plattform-Admins mit lesbarer Anmeldung vorgesehen; technische Konten können sie nicht verwenden.

Wie wird ein Hinweis versendet?

Ein Hinweis beginnt als Entwurf. Vor dem Versand kann die E-Mail in den angebotenen Sprachen geprüft und die Zahl der Empfänger ermittelt werden. Erst eine gesonderte Bestätigung startet den Versand. Hat sich die Empfängerzahl geändert, muss sie erneut ermittelt werden.

Der Hinweis richtet sich in der Anwendung an Beratungsstellen-Admins. Eine E-Mail kommt zusätzlich in Betracht, wenn die Person sie aktiviert und eine verwendbare Adresse hinterlegt hat.

System notices

Platform admins can use system notices to announce planned maintenance to counselling-centre admins.

Who can use it?

The view is intended for platform admins with a readable login; technical accounts cannot use it.

How is a notice sent?

A notice starts as a draft. Before sending, the email can be previewed in the offered languages and the recipients counted. Sending starts only after a separate confirmation. If the recipient count has changed, it must be counted again.

The notice targets counselling-centre admins in the application. Email is also considered when the person enabled it and has a usable address.
