Erste Nachricht an Ratsuchende

Ein Träger kann Teile der ersten Nachricht an Ratsuchende und die angegebene Antwortfrist bearbeiten und veröffentlichen.

Wer kann die Einstellung ändern?

Die Bearbeitung hängt von der Berechtigung zum Ändern des Trägers ab. Ohne diese Berechtigung bleibt die Ansicht schreibgeschützt.

Was passiert beim Veröffentlichen?

Die bearbeiteten Inhalte und gegebenenfalls die Frist werden für den Träger gespeichert. Die Oberfläche bietet an, die Texte vor der Veröffentlichung zu übersetzen. Eine fehlgeschlagene Übersetzung veröffentlicht nicht automatisch; sie kann erneut versucht oder übersprungen werden.

Für Felder ohne eigenen Text gelten die angegebenen Plattformvorgaben. Die Anwendung stellt die Nachricht aus den verfügbaren Bausteinen zusammen.

First message to advice seekers

A provider can edit and publish parts of the first message to advice seekers and the stated response deadline.

Who can change the setting?

Editing depends on permission to change the provider. Without that permission the view is read-only.

What happens when you publish?

The edited content and, when changed, the deadline are saved for the provider. The interface offers to translate the texts before publication. A failed translation is not published automatically; it can be retried or skipped.

Fields without their own text use the stated platform defaults. The application assembles the message from the available parts.
