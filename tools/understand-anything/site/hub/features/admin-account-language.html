Sprache im eigenen Konto

In dieser Kachel wählen Sie die Sprache der Admin-Oberfläche aus.

Was passiert bei der Auswahl?

Die Oberfläche wechselt zur gewählten unterstützten Sprache. Die Auswahl wird im Browser gespeichert und kann später wieder geändert werden.

Language in your account

Use this tile to choose the language of the Admin interface.

What happens when you choose?

The interface switches to the selected supported language. The choice is stored in the browser and can be changed again later.
