  2. 2
    Die Hilfe an der Kachel öffnenOpen help on the tileAdministrationAdministration
    Öffne an der Kachel die Info-Schaltfläche „Erklärung öffnen: [Titel]“. Mit „Weiter“ liest du die nächste Seite, mit „Fertig“ schließt du die Hilfe. „Mehr dazu“ öffnet verknüpfte Erklärungen, sofern das Thema welche anbietet.On a tile, use the information button “Open explanation: [Title]”. Use Next to read the next slide and Done to close the help. “More on this: [Title]” opens related help when available.

    Admin-Tour richtig einordnenUnderstand the Admin tour statusAdministrationAdministration

Für Einstellungen im laufenden Admin nutze die Erklärung direkt an der jeweiligen Kachel.No Admin tours are registered in the checked Admin source. The demo tour runs in Storybook. For settings in the live Admin interface, use the explanation on the relevant tile.
