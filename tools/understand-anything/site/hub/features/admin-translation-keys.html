Automatische Übersetzung

In dieser Kachel hinterlegt die Plattform Zugangsschlüssel für die Übersetzungsanbieter OpenRouter und Mistral. Damit können unterstützte Texte auf Anforderung automatisch übersetzt werden.

Wer kann die Einstellung ändern?

Plattform-Admins können Schlüssel speichern. Träger-Admins, die diese Seite öffnen können, sehen die Kachel ohne Bearbeitungsrecht.

Was passiert beim Speichern?

Ein neuer Schlüssel ersetzt den bisherigen Schlüssel für den gewählten Anbieter. Ein gespeicherter Schlüssel wird in der Oberfläche nur gekürzt angezeigt. Ohne hinterlegten Schlüssel kann der zugehörige Dienst nicht verwendet werden.

Wenn eine Funktion keinen Anbieter vorgibt, verwendet der Dienst zuerst OpenRouter, sofern dort ein Schlüssel hinterlegt ist; andernfalls Mistral. Die Übersetzung startet, wenn jemand sie in einer unterstützten Funktion auslöst.

Automatic translation

This tile stores the platform's access keys for the translation providers OpenRouter and Mistral. They allow supported texts to be translated on request.

Who can change the setting?

Platform admins can save keys. Provider admins who can open this page see the tile without editing rights.

What happens when you save?

A new key replaces the previous key for the selected provider. A stored key is shown only in shortened form in the interface. Without a stored key, the corresponding service cannot be used.

When a feature does not specify a provider, the service uses OpenRouter if a key is stored there, otherwise Mistral. Translation starts when someone requests it in a supported feature.
