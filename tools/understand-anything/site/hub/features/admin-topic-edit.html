Thema anlegen und bearbeiten

Auf dieser Seite pflegen berechtigte Admins Name, Beschreibung, internen Bezeichner und Status eines Themas.

Was passiert beim Speichern?

Name und Beschreibung können für unterstützte Sprachen eingegeben werden. Die Einstellungen enthalten den erforderlichen internen Bezeichner und den Status. Beim Anlegen werden die Angaben gemeinsam gespeichert; bei einem vorhandenen Thema können die Bereiche bearbeitet werden.

Die Ansicht setzt das Recht voraus, Themen anzulegen oder zu ändern. Für die Themen-Admin-Rolle hängt dieses Recht davon ab, dass Themen aktiviert sind; zusätzliche Rollen können Rechte ergänzen. Die Auswirkungen eines Statuswechsels in allen Diensten sind noch nicht vollständig geprüft.

Stand und Quellen

Die beschriebene Ansicht ist im Quellcode vorhanden. Diese Seite bestätigt keine laufende Bereitstellung. Stand: 5. November 2026.

Create and edit a topic

Authorised admins use this page to maintain a topic’s name, description, internal identifier and status.

What happens when you save?

Name and description can be entered for supported languages. The settings include the required internal identifier and the status. When creating a topic the details are saved together; for an existing topic the sections can be edited.

The view requires permission to create or update topics. For the topic-admin role, that permission depends on topics being enabled; additional roles can add permissions. The effects of a status change across all services have not yet been fully checked.

Status and sources

The view described is present in source code. This page does not verify a running deployment. As of 5 November 2026.
