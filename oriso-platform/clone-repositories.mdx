# Clone ORISO Repositories

Clone the current chart into your workspace. The `online-counseling` chart lives at the root of ORISO-Helm.

```bash
mkdir -p ~/online-beratung
cd ~/online-beratung
git clone https://github.com/OpenResilienceInitiative/ORISO-Helm.git
cd ORISO-Helm
ls Chart.yaml charts templates
```

For service changes, clone the repository that owns the service. The UserService, AgencyService, TenantService and ConsultingTypeService repositories also hold their changelogs. The app and admin UI live in ORISO-Frontend and ORISO-Admin. [Repository map](/docs/platform/repository-map)
