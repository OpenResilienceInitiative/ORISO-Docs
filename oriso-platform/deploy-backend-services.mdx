# Deploy backend services

Use the [ORISO-Helm umbrella chart](/docs/platform/kubernetes-deployment). Select the chart revision and released images approved for the environment. Render the target configuration before applying it and compare workload image references and changes to persistent storage and jobs with the current release.

For an existing installation, confirm the recovery point and the [schema upgrade path](/oriso-platform/setup-databases) before rollout. Follow the operator's deployment order for dependent services, and use the [Keycloak chart configuration](/oriso-platform/configure-keycloak).

After rollout, use the [post-deployment checks](/oriso-platform/post-deployment) to match readiness and a functional test to the running versions.
